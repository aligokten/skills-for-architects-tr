# mimarlik-bilgisi-tr

Türkiye'de mimarlık meslek pratiğini kaynaklı olarak açıklar: proje aşamaları (avan, uygulama), proje müellifi, şantiye şefi, yapı denetim, ruhsat/iskân süreci, Mimarlar Odası hizmet şartnamesi ve en az bedel, yapı sınıfları ve Yapı Yaklaşık Birim Maliyetleri. "Uygulama projesi nedir", "hizmet bedeli nasıl hesaplanır" için kullan.

Güncel prosedür için [beceri dosyasına](SKILL.md), kayıtlı asıl kaynaklar için [kaynak kataloğuna](../../corpus/sources/catalog.json) bakın. Kaynak üst verisi, erişilmiş kanıt veya kapsam garantisi değildir.
