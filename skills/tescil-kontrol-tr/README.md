# tescil-kontrol-tr

Türkiye'de bir taşınmazın tescilli kültür varlığı olup olmadığını, sit alanı veya koruma alanında kalıp kalmadığını 2863 sayılı Kanun ve Koruma Bölge Kurulu kararları üzerinden kontrol eder. "Bu bina tescilli mi", "sit alanında mı", "kurul izni gerekir mi" için kullan.

Güncel prosedür için [beceri dosyasına](SKILL.md), kayıtlı asıl kaynaklar için [kaynak kataloğuna](../../corpus/sources/catalog.json) bakın. Kaynak üst verisi, erişilmiş kanıt veya kapsam garantisi değildir.
