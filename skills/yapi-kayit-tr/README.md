# yapi-kayit-tr

Türkiye'de bir yapının ruhsat, iskân (yapı kullanma izni), yapı denetim, yapı kayıt belgesi (imar barışı) ve riskli yapı (6306) geçmişini kullanıcının belgeleri ve resmî kaynaklarla araştırır. "Ruhsatı var mı", "iskânı alınmış mı", "riskli yapı mı" için kullan.

Güncel prosedür için [beceri dosyasına](SKILL.md), kayıtlı asıl kaynaklar için [kaynak kataloğuna](../../corpus/sources/catalog.json) bakın. Kaynak üst verisi, erişilmiş kanıt veya kapsam garantisi değildir.
